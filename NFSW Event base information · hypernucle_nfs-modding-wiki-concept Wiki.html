NFSW Event base information

Jump to bottom
Hypercycle edited this page Aug 29, 2020 · 1 revision

All events is based on a special configuration node, which I call as "Event Configuration". It sets and describes the main event attributes - the track layout, access parameters, conditions, and more. To create a working event, you will also need to create the "TrackLayout", which contains the race track itself.

Let's take a look on the one of the most popular game events, "Consturction Route". In the VLT-base, this event can be found on the "gpcore" pack, with eventId 43.

Now we will check, what line means.

- ParentName: p2p

  • Name of the "parent" node - it can be located anywhere on the VLT-base, works like folders hierarchy. The "child" node (our event in this case) will get all parameters of the "parent" node. Useful for code navigation and to store common parameters for the multiple nodes.

Name: race_bin_1to5/noob2

  • Name of our node. As the parentName, can be used for a folder structure, but doesn't take the information from the previous "parent" nodes. Examples:
    storage/item - the "item" will be on the "storage" folder.
    item - the "item" will be on the "parent"-related folder.

After that, the "Data" block comes with main node data:

CollectionName: race_bin_1to5/noob2

  • Name of the current collection. Used on the collection-type nodes, and usually equal to the "name" parameter.

Template: false

  • Not used by the game. Use the "parent" nodes to keep the common parameters for the multiple events.

Children:

  • Activates the nodes with their own attributes.
    ! Usually, NFSW events have a lot of the "Children" nodes, which is not directly used by the game anymore (since the same stuff located on TrackLayout or other dependent nodes). As I guess, developers have used a event-converter, to transfer MW-Carbon events into the World platform, with additional information.

Description: Construction Route

  • Event description. Not used by the game, but can be used for the code navigation purposes.

EngageTrigger:
___ClassKey: gameplay
___CollectionKey: race_bin_1to5/noob2/engage

  • Event's join point on the world map of free-roam mode. Locates the EngageTrigger node with position coordinates.

EngageTriggerPosition:
___X: 4797.921875
___Y: 295.697998046875
___Z: 32.256301879882812

  • Obsolete EngageTrigger position values and not used by the game, set up the EngageTrigger node with values above.

EventId: 43

  • Number of the Event ID, unique for each event. Can be anything from 0. Original game events is going from 0, up to ~550.
    ? Community-made events usually take a 600+ number space (World Evolved server uses 1000+ number space for the event clones).

IsEnabled: false

  • Not used by the game as the static VLT value. The availability of the event is controlled on the server-side (Event/isEnabled parameter).

Localization: 953953223

  • Hash value of the event's name. Stored on the language files and can be different for the various languages.
    ? Russian localization had a fully translated event names, but reverted back to the english names on 2012.

MaxLevel: 60

  • Not used by the game as the static VLT value. The maximum access level is controlled on the server-side (Event/MaxLevel parameter).

MinLevel: 2

  • Not used by the game as the static VLT value. The minimum access level is controlled on the server-side (Event/MinLevel parameter).

Name: race_bin_1to5/noob2

  • Name of the node. Used for the code navigation purposes.

TrackLayout:
___ClassKey: gameplay
___CollectionKey: tracks/track175

  • A link to the TrackLayout node. Defines the track's route, can be swapped with any other existing layout node.

TrackLength: 4.4399638175964355

  • A track's length. Game displays it as the "4,43 km".

TrafficDensity: 1

  • Traffic cars density. Can be from 0 (no traffic) up to 10 (maximum traffic).

ZoneId: 7

  • World's zone ID of the track (In this case, Downtown). Not used by the game.

Additional parameters

DifficultyLevel: 100

  • Difficulty level of the AI drivers. Values from 0 to 100.
    ! NFSW's AI is kinda weak, so feel free to use a high values.

EventModeIcon: GAMEMODEICON_YOURICON

  • Icon of the event's mode, but can be set up for the each event. Displayed on the MultiPlayer/SinglePlayer selection menu.
    ? The icons are being picked from "IconsEventTypes" file on the GLOBAL folder.

OpponentCount: 5

  • Controls the amount of the AI drivers. Values from 0 (no AI drivers) to the 8 (full grid).

NumLaps: 2

  • Number of the laps (Circuit-only). Can be from 1 to 99.
    ! Values higher than 30 is not recommended for the online-racing.

EventModeDescriptionLocalization: 1517873707

  • Event's mode name hash, displayed on the event window. Stored on the language files and can be different for the various languages.

Hud:
_Capacity: 4
_Data:
___- InstrumentCluster
___- PowerUp
___- PowerUpBuffBar
___- RankingHUDCircuit

  • A list of the HUD elements on this event. The unlisted-elements are disabling related HUD-element actions.
    ! Usually being located once for every event type, but can be used for the event separately - for example, remove the power-ups or map gadget.

AIShortcutPct: 0

  • How much the AI drivers will use the shortcuts on the track. Values from 0 to 100.

AIUsePowerUps: false

  • Allow to use power-ups for AI drivers. Can be true or false.

CarClass:
___ClassKey: gameplay
___CollectionKey: server/car_classes/carclass_a

  • Car class restriction for the AI drivers (if they don't have a defined driver profile). Every "car class" node have it's own car rating limits.
    ! Remove this parameter to allow AI drivers to try pick the cars of your class or higher.

PowerupBlackoutAtEventStart: 10

  • Disable the power-ups on the event start, value in seconds.
    ? Player's skill "Fast Powerups" can reduce this value.
